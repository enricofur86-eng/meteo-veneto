# Meteo Veneto

App Android gratuita e senza pubblicità con le previsioni del bollettino ufficiale ARPAV
(18 zone del Veneto, fino a 5 giorni).

- Fonte dati: https://meteo.arpa.veneto.it/meteo/bollettini/it/xml/bollettino_utenti.xml
- Nessuna libreria esterna, nessun tracciamento.
- L'ultimo bollettino resta salvato e si vede anche senza rete.

## Compilare
Ogni push su GitHub avvia l'azione "Compila APK", che pubblica una Release con
`MeteoVeneto.apk`: si scarica da https://github.com/enricofur86-eng/meteo-veneto/releases/latest

App non ufficiale, non affiliata ad ARPAV.
